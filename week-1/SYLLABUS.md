# WEEK 1: LINUX & CYBERSECURITY FUNDAMENTALS - SYLLABUS

**Duration:** 20-25 hours
**Level:** Beginner
**Format:** OverTheWire Bandit CTF (Levels 0-15)

## 📋 Week Objectives

By the end of Week 1, you will master:
- ✅ Linux file system navigation and manipulation
- ✅ File permissions (user, group, other)
- ✅ Command-line utilities (grep, find, sort, uniq, etc)
- ✅ SSH connections and remote access
- ✅ Data encoding and decoding
- ✅ File type detection
- ✅ Bash scripting basics
- ✅ Problem-solving mindset

## 📅 Daily Schedule

### Day 1: Levels 0-5 (Basic Commands)
- Level 0→1: cat command
- Level 1→2: Special characters
- Level 2→3: Spaces in filenames
- Level 3→4: Hidden files (ls -a)
- Level 4→5: File type detection

### Day 2: Levels 6-10 (Intermediate)
- Level 5→6: find -size filter
- Level 6→7: find with multiple filters
- Level 7→8: grep pattern matching
- Level 8→9: sort + uniq -u
- Level 9→10: strings command

### Day 3: Levels 11-15 (Data Encoding)
- Level 10→11: Base64 decoding
- Level 11→12: ROT13 cipher
- Level 12→13: Hexdump + compression
- Level 13→14: SSH private keys
- Level 14→15: Netcat (TCP connections)

## 🎯 Learning Outcomes

**Knowledge:**
- Linux file hierarchy and permissions
- Command-line tools and utilities
- SSH protocol and key authentication
- Data encoding (Base64, ROT13, hex)

**Skills:**
- Navigate filesystem efficiently
- Use command-line tools effectively
- Read and analyze files
- Connect to remote systems
- Decode data formats
